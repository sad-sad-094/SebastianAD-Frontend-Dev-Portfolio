## About Me

Frontend Developer with 3+ years of experience building scalable, high-performance single-page applications for SaaS products and enterprise platforms. I specialize in the **Vue.js and React ecosystems**, with a strong focus on component architecture, state management, API integration, and mobile-first performance optimization.

I apply **SOLID principles and Clean Architecture** as foundational pillars in every project — not as methodology, but as a mindset for building interfaces that are decoupled, predictable, testable, and resilient to business changes.

Currently expanding into full-stack development with **Node.js**, and actively leveraging **AI-assisted development workflows** (Claude Code) as part of my daily engineering practice.
